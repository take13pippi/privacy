Our Homework Log Support

Last updated: October 24, 2026

"Our Homework Log" is a homework tracker for families. A parent adds the homework from school, cram school, or after-school classes, and the child taps to record "Done!" as they go. This page covers the basics and frequently asked questions.

How to use

  1. On the Add tab, a parent adds homework. Just enter the subject, the workbook or task, and the page range (e.g. 62-63, or 86, 98-99). Homework without pages, such as corrections or memorizing, can be added as "Check only".
  2. The Log tab is your child's screen. Homework is shown as big cards, and tapping a finished page moves the progress forward by that much. When everything is done, a "Great job!" flower stamp appears.
  3. On the Progress tab, the family can check the homework to do before the next class, and progress by subject and by date.

Open Settings with the gear button at the top right of the Add tab. This is where you'll find the display language, subject names, colors, and order, your children's profiles, saving and importing data, and the cloud sync settings. From "Support" in Settings, you can open this page or send feedback and problem reports by email.

Subjects and class days

The app starts with four subjects: Math, Reading, Science, and Social Studies. In Settings > "Subjects", you can change their names, colors, and order, or add more subjects.

If you set the class days for a subject (the days that subject has class, for example at a cram school), the Add tab automatically fills in "Date assigned" with the latest class day and "Due date" with the next class day (you can change them). "Homework until the next class" on the Progress tab then counts the homework given between the last and the next class, plus anything left over. Class days can be set for each child.

FAQ

Does it cost anything?

Downloading the app and the basic features are free. If you use it on one device only, adding homework, recording it, and checking progress are all free, with no time limit. Cloud sync and separate profiles for siblings are included in the "Premium Pack", a one-time purchase. There's no monthly fee, and no ads are shown.

Do I need an account?

No. You can start using it right after you install it.

Where is my data saved?

On your device. If you use cloud sync (optional), it is also saved to a file in the cloud that you chose. In either case, it is never sent to the developer's servers. See the Privacy Policy for details.

How can my family see the same homework on their devices?

Use "Cloud sync" in the Premium Pack.

  1. On the first device, go to Settings > "Advanced" > "Cloud sync" > "Connect to the cloud" > "Create a new file (first device)", and save the file somewhere your family can share, such as iCloud Drive, Google Drive, or Dropbox.
  2. On the second and later devices, choose that file from the same place with "Choose an existing file (second device onward)".

Changes can take a few seconds to a few minutes to show up, depending on when your cloud syncs. Pull down on the screen to sync right away.

Families with both iPhone/iPad and Android devices can share too, as long as everyone chooses the same file. In that case, save it in Google Drive or Dropbox, which both kinds of devices can open.

How many family devices can use one purchase?

Up to 5 devices that join the same sync file. You can remove devices you no longer use from the "Devices in use" list in Settings (from any of the devices). The list shows when each device was added, so you can also tell which one is the old device you used before switching.

I bought it, but the features don't work / I switched to a new device

Try "Restore purchase" in Settings. You need to be signed in to your store with the same account you used to buy it.

  • iPhone / iPad: the same Apple Account you bought it with
  • Android: the same Google Account you bought it with

Right after you switch store accounts, it can take a while for the purchase info to reach your device, and restoring may not work. If that happens, tap "Buy". If you've already bought it, you won't be charged twice, and it will just start working.

Devices that use a family member's purchase (devices where you didn't buy it yourself) start working again when you reconnect them to the same file with cloud sync, not by restoring.

Can siblings use it?

Create a profile for each child to keep their homework separate. Setting the first child's name is free; adding a second child or more needs the Premium Pack. Subjects are shared by the whole family.

I can't type "-" or "," in the page range

There are "-" and "," buttons right below the page range field, so you can enter them while keeping the number keyboard.

I want to fix or delete homework I added

In the "Added homework" list at the bottom of the Add tab, tap the pencil button to edit, or the trash can button to delete. You can also select several with the checkboxes and delete them at once. If you change the page range, the record of the pages already finished is kept.

What should I do when I change devices?

In Settings, save your data to a file, then import it on the new device. If you use cloud sync, just connect the new device to the same file.

I deleted my data. Can it be restored?

The developer can't restore deleted data. We recommend saving your records to a file from time to time as a backup.

Can I change the language?

The app supports 日本語, English, 한국어, and 繁體中文. It normally follows your device's language, and you can also choose one from "🌐 言語 / Language" at the top of Settings.

Which devices are supported?

  • iPhone / iPad: iOS 15.0 or later
  • Android: phones and tablets with Android 8.0 or later
Reporting a problem
If you send it from Settings > "Support" > "Feedback / report a problem (email)", the app and OS versions are added to the email automatically. It also helps us find the cause if you include the following:
  • Your device model (e.g. iPhone 13, Pixel 10) and OS version (if you send it from the app, the OS version isn't needed)
  • Which screen you were on and what you did when it happened
  • A screenshot, if possible
